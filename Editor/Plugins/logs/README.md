# Logs

Просмотрщик логов **Play-прогона**. Захват идёт в `LogCollector` с момента загрузки редактора — независимо от того, открыто ли окно Nexus; страница только показывает буфер.

Вне Play не захватывается ничего: это визуализатор запущенной игры, а не замена Console.

## Уровни и теги

Уровень записи выводится из типа Unity и из токенов `[...]` в тексте. Приоритет:

1. тег `[Error]` — безусловно Error
2. настоящий `LogError` / `Exception` / `Assert` — Error
3. тег `[Warning]` / `[Warn]`
4. настоящий Warning
5. тег `[Debug]`
6. тег `[Info]`
7. иначе базовый тип (обычный `Debug.Log` → Info)

Любой другой токен `[...]` становится **тегом**: вырезается из отображаемого сообщения и превращается в чип-фильтр. Теги-имена уровней чипами не показываются — они уже видны бейджем уровня.

```
Debug.Log("[Netcode][Warning] пакет потерян");
```

Уровень — Warning, чип — `Netcode`, сообщение — `пакет потерян`.

## Сбор

- маска уровней: выключенный уровень **не сохраняется** в буфер (влияет только на новые логи)
- ёмкость (по умолчанию 1000): при переполнении вытесняется самый ранний
- буфер переживает доменную перезагрузку через `SessionState`, но стирается при отключении плагина
- маска и ёмкость лежат в `EditorPrefs` и disable переживают

## Фильтры показа

- маска уровней с живыми счётчиками на кнопках
- **Последняя сессия** — только текущий Play-прогон (в Edit mode — последний); id прогона растёт на `ExitingEditMode`, поэтому самые ранние стартовые логи уже попадают в новую сессию
- чипы тегов со счётчиками, совпадение по **любому** выбранному (ИЛИ)
- текстовый поиск по сообщению и по исходной строке

## Список

- отрисовывается не более 500 строк
- **Свернуть** — подряд идущие одинаковые записи схлопываются в одну с `×N`
- **Пауза** — вид замораживается, сбор продолжается
- **Автопрокрутка** — держит низ, если пользователь оттуда не ушёл
- `A-` / `A+` — размер текста строки, 8–22 px
- клик по строке раскрывает стек; кадры с путём в проекте кликабельны и открывают файл на нужной строке
- контекстное меню строки: копировать сообщение, копировать стек, перейти к источнику
- **Экспорт** — отфильтрованное в `.txt`
- перестройка дросселируется до ~8 fps, поллинг живёт только пока окно в фокусе

## Устройство

Constitutive-плагин: всё замкнуто на себе, наружу файлов не пишет, disable стирает и State, и рабочий буфер.

- `LogModel.cs` — `LogEntry`, `LogParser`, `StackTraceUtil`; чистый потокобезопасный парсинг
- `LogCollector.cs` — `[InitializeOnLoad]`-компонент-с-состоянием: кольцевой буфер, реестр тегов, счётчик сессий
- `LogsPage.cs` — тулбар, лайфцикл, состояние вида
- `LogsPage.Filters.cs` — панели сбора/показа, чипы тегов, предикат фильтра
- `LogsPage.List.cs` — рендер строк, стеки, экспорт
- `LogsPage.Theme.cs` — покраска по токенам палитры

Сборщик — не сервис: у него есть поля, переживающие вызов. Его ось «off means off» — «плагин задеплоен», а не «окно открыто»: при disable `.cs` выселяется из `State/`, `[InitializeOnLoad]` не срабатывает, работы ноль.

Цвета берутся через `Context.Theme.Get(token)` — страница не видит ассембли Theme; USS отвечает только за раскладку. Зависимостей нет: asmdef ссылается лишь на `Exerussus.Nexus.Abstractions`.

## Состояние

- `SessionState`: маска показа, поиск, активные теги, пауза, «последняя сессия»
- `EditorPrefs`: автопрокрутка, свёртка, размер шрифта, маска сбора, ёмкость
