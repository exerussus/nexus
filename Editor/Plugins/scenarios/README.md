# Scenarios

Сценарии запуска: список сцен проекта, к каждой можно прикрепить сценарий запуска, влияющий на то, как пойдут процессы игры.

## Возможности

- Список сцен: добавление перетаскиванием SceneAsset в поле **Add** или кнопкой **+ Open Scenes** (все открытые сцены разом)
- **Switch** — открыть сцену в Edit Mode
- **Play** — открыть сцену и войти в Play Mode по выбранному сценарию
- Перетаскивание строк меняет порядок списка
- *Ask to save before switch* — спрашивать о сохранении изменений перед переключением
- *Return to original after Play* — если перед запуском открывалась другая сцена, после Stop вернуть исходную

## Хранение

Список сцен и опции — персональные. Файл: `UserSettings/Exerussus.Nexus/scenarios/scenarios.json` (не попадает в git, переживает Restore и Disable). Кнопка **Config** в тулбаре показывает файл в проводнике.

Сцены хранятся по GUID ассета — переименование и перемещение сцен не ломают записи. Запись с удалённой сценой помечается как *(missing scene)*.

## Сценарии запуска

Колонка **Scenario** в строке сцены — сценарий запуска (`LaunchScenario` из пакета `com.exerussus.scenario`; хаб предложит установить пакет при включении страницы). Клик по бейджу — выбор сценария из всех сценариев проекта. Сценарии — обычные ассеты (`Assets → Create → Exerussus → Scenario → Launch Scenario`), коммитятся и шарятся командой; какой сценарий привязан к какой сцене — личный выбор в `scenarios.json`.

Сценарий не про сцену: внутри него аргументы, которые исполняются перед входом в Play Mode и меняют протекание конкретных процессов игры. Сцена — лишь место, где сценарий исполняется.

При нажатии **Play** со сценарием страница взводит intent, пакет исполняет аргументы перед входом в Play Mode, а игра читает их через `ScenarioArgs.TryGet` — подробности в README пакета. Если пакет не установлен или сценарий удалён, запуск происходит без аргументов с предупреждением в статусе.

## Обновление с 1.1 (страница Scenes)

Переименование ломающее: `id` страницы сменился с `scenes` на `scenarios`, версия контракта с пакетом поднята до 2.

- Хаб перепривяжет плагин по неизменному `guid`, но старый `NexusStates/scenes/` останется сиротой — почистить через Manage.
- Персональный конфиг **не мигрирует автоматически**: страница не имеет права строить хабовые пути. Либо собрать список сцен заново, либо руками переименовать `UserSettings/Exerussus.Nexus/scenes/` в `scenarios/`, файл `scenes.json` в `scenarios.json` и ключ `ArgSetGuid` внутри в `ScenarioGuid`.
- Пакет обновить одновременно со страницей: `com.exerussus.scene-launch` снести, поставить `com.exerussus.scenario`. Рассинхрон версии контракта гасит аргументы с ошибкой в консоль.
