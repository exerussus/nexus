# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [0.4.1]

### Исправлено
- Шрифты хаба: материал и атлас собранных в памяти шрифтов защищены от выгрузки. Смена сцены, вход в префаб
  или сборка неиспользуемых ассетов больше не роняют отрисовку окон Nexus (`MissingReferenceException: Material`
  в `TextUtilities.GetTextCoreSettingsForElement`, за ним `InvalidOperationException` в рендере UI Toolkit).
  Шрифт без материала или атласа пересобирается при следующем обращении.

## [0.4.0]

### Добавлено
- Палитра **Neon** — новая по умолчанию: сине-чёрные поверхности, приглушённый бирюзовый неон,
  свечение активного и фокуса, HUD-уголки карточек, фоновая сетка, моноширинные заголовки капслоком.
  Soft Dark и Graphite остаются в Manage и тоже доведены: свои цвета полей, ссылок, кода и меток,
  мягкое свечение фокуса, скругления; у Graphite — моноширинные заголовки и тонкая сетка.
- Шрифты хаба в пакете: Inter (основной) и JetBrains Mono (заголовки Neon, код), лицензия OFL рядом
  (`Editor/Theme/Fonts`). Жирное — настоящее начертание через таблицу весов.
- Токены: `BgInset` (поля и код), `AccentText` (ссылки и активный текст), `Code`, метки
  `TagAmber/Green/Blue/Violet` с мягкими парами, эффекты `Glow`, `Bracket`, `Grid`. Добавлены в конец
  перечисления — значения прежних не сдвинулись.
- `NexusMetrics` (`IPageTheme.Metrics`): скругления S/M/L и характер заголовков палитры, шаги отступов
  и кегли.
- `IPageUi`: `Title`, `Code`, `Tag`, `ListRow`, `Glow`, `Brackets`, `ApplyTheme`.
- Классы-токены `NexusClass` (Abstractions): цвет текста, фона и рамки любым токеном палитры —
  `nx-fg--<token>`, `nx-bg--<token>`, `nx-bd--<token>` (`Uss/NexusTokens.uss`, генерируется вместе
  с палитрами). `SetFg/SetBg/SetBorder` меняют состояние без аллокаций. Страница больше не держит
  цвета в коде. Плюс общие классы для страниц: `nx-text`, `nx-hint`, `nx-label`, `nx-empty`,
  `nx-kv`, `nx-bar`, `nx-inset`; списки Unity (ListView) выбирают цветами палитры.
- Плагин `app` 3.2: вкладка «Локализация».
  - **Таблица:** список ключей с предпросмотром и типом строки, конструктор выбранного ключа —
    режимы «простой текст / с аргументами / зависит от числа», аргументы с описанием и примером
    (комментарием в `.loc`), формы окончаний с подсказками чисел, вставка в позицию курсора
    (аргументы, живые значения из каталога проекта, жирный, цвет, перенос), проверки с исправлением
    в один клик, предпросмотр по числу, готовый код; скан использований, ключи вне таблицы.
  - **Языки и окончания**, **Патчи** (слои, перекрытия, история ключа в Play Mode; проверка файла
    патча вне игры), **Настройки** (инспектор, генерация `L`, проверка ключей, импорт старого JSON),
    **Справка** (рецепты с кодом и переходом к примеру в таблице).

### Исправлено
- Выбор палитры в Manage применял предыдущую: окно Nexus пересобиралось по смене палитры раньше,
  чем выбор сохранялся, и откатывало его. Теперь выбор сохраняется первым; сам выбор — сегменты
  в стиле хаба вместо светлого меню редактора.
- Страница, упавшая при сборке, пишет в консоль полный стек, а не только сообщение.

### Изменено
- Вид компонентов описан в USS (`Editor/Theme/Uss/NexusComponents.uss`, классы `nx-*`), значения —
  переменные палитры (`Uss/<Palette>.uss`, генерируются из C#-палитры: Exerussus/Nexus/Dev/Regenerate
  theme USS). Наведение, нажатие, фокус и выбор — псевдоклассы вместо колбэков на каждом элементе;
  смена палитры перекрашивает уже построенное. `NexusStyles.MakePressable` оставлен для своих
  виджетов страниц.
- Страницы на стиле хаба (цвета — только классы и переменные палитры):
  - **ECS Worlds** 1.1: вкладки и переключатели — `Tabs`/`Segmented`, миры и архетипы — `ListRow`,
    карточки компонентов — `Card` + `Code`, фишки фильтра и счётчики — свои классы на токенах.
  - **Рабочая область** 1.3: группы и карточки — USS с состояниями (наведение, закреплено,
    отсутствует, вспышка) вместо колбэков, свечение карточек, кнопки тулбара — роли хаба.
  - **Salamander** 2.1: компактные кнопки хаба; оболочка IDE — выбор и наведение токенами
    `AccentSoft`/`Hover` (IDE в пакете принимает цвета структурой — USS хаба до неё не доходит).
  - **App**: `AppKit` и вкладки — классы-токены вместо инлайн-цветов.
- Окно Nexus: тулбар, сайдбар (выбранная страница — полоса акцента слева; у палитр с моноширинными
  заголовками — тем же шрифтом), разделы, сетка под
  страницей. Страница App и её набор (`AppKit`) — на компонентах хаба.

### Требуется
- app-core 4.4.0+ (раньше страница не скомпилируется).

## [0.3.1]

### Добавлено
- Плагин `app` 3.1, «Сборка → Пайплайн»: пост-шаг «Заливка в PlayFlow» (`playflow-upload`). Заливает серверную
  сборку в PlayFlow Cloud через Public API v3: zip шага Zip (или свой архив папки сборки), executable_path
  находится в архиве сам, ожидание обработки (при ошибке — хвост логов обработки), по желанию перезапуск
  сервера по instance id на новую версию и вывод нового адреса в лог. Серверный ключ — личный
  (UserSettings `playflow-credentials.json`) или переменная окружения; без ключа шаг пропускается.
  Важно: при перезапуске PlayFlow выделяет новые host и порт — клиент должен узнавать адрес по instance id.

## [0.3.0]

### Изменено
- Плагин `app` 3.0, «Сборка → Пайплайн»: контракт шагов (`BuildStep<T>`, `[BuildStep]`, `BuildStepContext`,
  `BuildTokens`) переехал в app-core 4.3 (`Exerussus.AppCore.Editor.Build`). Шаги ищутся во всех сборках
  проекта — пакет со ссылкой на `Exerussus.AppCore.Editor` может принести свой шаг; у такого шага в пайплайне
  подписано, из какой он сборки. UI настроек шага получает `IBuildStepHost` (поля, кнопки, статус, личные
  файлы в стиле страницы). Id и настройки встроенных шагов не изменились — build-config.json тот же.
- Два шага с одинаковым id: второй пропускается с ошибкой в журнале.

### Требуется
- app-core 4.3.0+ (раньше страница не скомпилируется).

## [0.2.3]

### Изменено
- Плагин `app` 2.3, «Заливка в S3»: путь в бакете разделён на «Главную папку» (по желанию, по умолчанию

## [0.2.2]

### Добавлено
- Плагин `app` 2.2: пост-шаг «Заливка в S3 (rclone)» — папка сборки и/или zip в бакет. Общие настройки
  (endpoint, регион, бакет, папка в бакете по шаблону, sync/copy, исключения) — в `build-config.json`;
  ключи — личные (`UserSettings/…/app/s3-credentials.json`) или из переменных окружения, rclone получает
  их через окружение. Кнопка «Проверить подключение». Снятие маркеров папок Selectel перед sync.
  Заливка в корень бакета и папки с `..` запрещены.
- Шаг «Zip»: шаблон имени архива с токенами `{product} {version} {hash} {profile} {platform} {date}`
  (по умолчанию `{product}_{version}_{hash}` — как раньше) и предпросмотр.

### Исправлено
- История сборок: размер архива брался из первого артефакта (например, `version.json`), теперь — из `.zip`.

### Изменено
- Контракт шага сборки: `BuildSettingsUI(settings, changed, AppKit kit)` вместо `IPageUi` — шагу доступен
  контекст страницы (личные файлы, статус); `BuildStepContext.UserConfigPath(file)` — личные файлы при сборке.

## [0.2.1]

### Добавлено
- Журнал сообщений (`NexusStatusLog`, ядро): всё, что страницы пишут в `Context.SetStatus`, копится
  (до 50 сообщений, в пределах сессии редактора, одинаковые подряд схлопываются) с источником и временем.

  непрочитанная ошибка. Падение страницы попадает в журнал со стеком.

### Изменено
- Строка статуса — одна строка с многоточием; клик или «подробнее ›» открывает окно сообщений.
  Соглашение: первая строка статуса — коротко, остальное — подробности.

  scene objects» — главный ассет резолвится без перебора объектов файла, для сцен перебор не делается.

## [0.2.0]

### Добавлено
- Корни плагинов по маркеру `nexus-plugins.json`: папка с маркером в Assets или в любом пакете
  становится корнем плагинов. Поиск — только кнопкой «Найти корни плагинов» в Manage; найденное
  хранится в `ProjectSettings/Nexus.json` (`discoveredRoots`, asset-пути, коммитится).
- Manage: секция «Корни плагинов» — встроенный, ручные и найденные корни, пропавшие и дубли.
- `NexusPaths.AssetToAbsolute`; `ToAssetPath` понимает пакеты из кэша (иконки плагинов из git-пакетов).
- `CHANGELOG.md`, README движка.

### Удалено
- Плагин `resources-auditor`. Если он был развёрнут, в Manage он станет «осиротевшим» — удалите его там кнопкой Clean.

### Изменено
- Nexus устанавливается как UPM-пакет: зависимость `com.unity.nuget.newtonsoft-json` объявлена
  в `package.json` (раньше Newtonsoft должен был быть в проекте сам). Если в проекте лежит
  Newtonsoft.Json.dll (NuGet и т.п.) — удалите его, иначе будет две сборки с одним именем.
- App 2.1: вариант «Текущий профиль» на вкладке Сборка собирает по активному Build Profile (сцены
  из его переопределения) и больше не переключает профиль на голую платформу.
- Workspace 1.1: из asmdef убрана ссылка на несуществующий asmdef `Newtonsoft.Json`
  (dll подхватывается авто-ссылкой).
