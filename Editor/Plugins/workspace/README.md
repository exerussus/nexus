# Рабочая область

*Scratchpad-страница для Nexus:* быстрые ссылки на ассеты, объекты сцены и внешние файлы в виде карточек, разложенных по сворачиваемым полкам.

## Возможности

- Drag & Drop ассетов, объектов сцены и внешних файлов прямо на полки.
- Клик по карточке — пинг и выделение; двойной клик — открыть/редактировать; alt+клик — убрать.
- Объекты сцены помнят свою сцену и предлагают перейти в неё перед пингом.
- Наборы: несколько объектов в одной карточке; Shift при дропе сворачивает выделение в набор.
- Закрепление карточек, фильтр по имени и типу, слайдер размера, переименование полок и наборов.

## Где хранится состояние

Личные данные пишутся в `UserSettings/Exerussus.Nexus/workspace/workspace.json` через `Context.GetUserConfigPath`. Они переживают *Restore* и *Disable* и стираются только командой *Clear settings*.

## Тип страницы

Образующая (*constitutive*): весь функционал замкнут на себя, ничего вне проекта не зависит от её вывода. При отключении развёрнутые файлы из `NexusStates/` удаляются — *off means off*.

## Заметки по интеграции

1. Тематизация — только через `Context.Theme.Get(token)`; прямой ссылки на сборку Theme у страницы нет.
2. asmdef ссылается лишь на `Exerussus.Nexus.Abstractions` и `Newtonsoft.Json`.
3. UXML и USS грузятся через `Context.LoadDeployedAsset`, без хардкода путей `NexusStates/`.
