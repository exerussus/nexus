# Resources Auditor

Показывает всё, что попадает в билд безусловно — папки Resources (в Assets и в пакетах)
и StreamingAssets — и выясняет, есть ли у каждого ассета подтверждённая причина там быть.

## Сканы (каждый — своя кнопка)

- **Скан Resources** — инвентарь: файлы, типы, размеры, load-пути. Точен на 100%.
- **Скан кода** — вызовы `Resources.Load / LoadAll / LoadAsync` по всем `.cs` проекта и пакетов.
- **Ссылки: сцены билда** — прямые ссылки на ассеты Resources из замыкания сцен Build Settings.
- **Ссылки: весь проект** — то же по всем ассетам проекта.
- **BuildReport** — фактические упакованные размеры из отчёта последнего билда.

## Вердикты

- **код** / **LoadAll** — грузится кодом, причина подтверждена.
- **только ссылки** — кандидат на вынос из Resources.
- **неизвестно** — данных мало или в проекте есть динамические загрузки.
- **мёртвый груз** — использований нет при полных данных.

> Вердикт «мёртвый груз» ставится только когда прогнаны скан кода и хотя бы один скан
> ссылок, а динамических вызовов в проекте нет.

Экспорт отчёта — Markdown или CSV, кнопками в тулбаре.
