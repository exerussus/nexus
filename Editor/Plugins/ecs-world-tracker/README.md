### ECS Worlds

Обозреватель живых ECS-миров форка **Exerussus.EcsLite** прямо в редакторе.
Показывает миры, сущности, компоненты и их значения — **без единого GameObject
или MonoBehaviour в сцене**. Миры регистрируются хуками внутри самого ECS.

---

### Как это устроено

- Страница читает мир **только на чтение** и **только рефлексией** через
  `Exerussus.EcsLite.EcsEditorBridge`. Сборка страницы не ссылается на ECS —
  изоляция Nexus цела.
- Это **обслуживающая** (servicing) страница: миры существуют независимо от неё.
- Форк ECS едет в плагине как инертный компаньон и разворачивается страницей
  **наружу**, в `Assets/Exerussus.EcsLite/` — внешний footprint, он **не
  стирается** при выключении страницы.

### Вкладки

- **Обзор** — три панели: миры · сущности · инспектор. Панели на полный рост,
  списки сущностей и карточки компонентов **скроллятся**.
- **Настройки** — развёртка ECS-ядра, частота автообновления и подсказка про
  имена миров.

### Первый запуск (вкладка «Настройки»)

1. **«Развернуть ядро»** — форк `Exerussus.EcsLite.cs` и `LICENSE` лягут в
   `Assets/Exerussus.EcsLite/`.
2. Убедись, что игра ссылается на сборку `Exerussus.EcsLite`.
3. Войди в **play mode** — миры появятся на вкладке «Обзор».

**«Удалить»** сносит **только** `Assets/Exerussus.EcsLite/` (папку создала эта
страница) с подтверждением.

### Автообновление

Обновляет данные, **пока окно открыто — даже без фокуса** (тик из
`EditorApplication.update`). В «Настройках»: пресеты **Вручную / 1 / 4 / 10 Гц**
и поле **«Своя частота, Гц»** — впиши любое число (например `2` или `0.5`).
«Вручную» отключает автообновление, оставляя кнопку **Refresh**.

### Обзор

- **worlds** — миры сгруппированы по владельцу-`EcsSystems`; карточка со
  статистикой `alive / used / cap / pools` и оценкой памяти.
- **entities** — режимы **List / Archetypes / Matrix(v2)**. Фильтр-чипы
  `+incl` / `−excl` по компонентам зеркалят `Mask.Inc/Exc`, но считаются на
  стороне страницы — фильтры в игровом мире **не создаются**.
- **inspector** — карточки компонентов со значениями полей; поля-ссылки на
  сущность кликабельны. `pin` держит выбор, `watch` перечитывает значения по
  таймеру.

### Имена миров

Имя можно задать прямо в конструкторе — оно станет меткой мира в дереве:

```
var combat = new EcsWorld(name: "combat");
// или:  new EcsWorld(cfg, "combat");
string n = combat.GetName();
```

Имя из `EcsSystems.AddWorld(world, name)` перекрывает имя из конструктора.

### Полное отключение

Инструментация обёрнута в `#if UNITY_EDITOR && !ECS_PROBE_OFF`. Определи
**`ECS_PROBE_OFF`**, и весь редакторный код (реестр, мост, хуки) исчезает —
ноль стоимости в билде.

> Тайминги/churn, спарклайны и профайлер систем — отдельный слой инструментации
> поверх этого моста (следующий патч).
